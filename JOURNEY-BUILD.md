# Astra-led journey: local playable slice

10 September 2026. Existing Site updated locally; no deployment. The original observatory, paint tools, orbital studio, trajectory comparisons and live orbital bridge remain available at `/atelier.html`.

## Try the three-minute demo

Run `python3 server.py` from this checkout if the local server is not already running. Open http://localhost:4173. Codex CLI authentication and access to `gpt-6-astra` are required for live conversation; no new API key is stored by this application.

1. Select L1 or another light. Look, drag, zoom, and inspect the bearing-only evidence. The expandable raw experiment can preview and apply a ship-axis impulse or change gravity without pretending to establish a homeward course.
2. Choose **Get us home. You drive.** The visible initial gross-spending cap is 75 fuel, 20 fictional Astra credits and 900 simulated years. Calibration is one six-credit investigation. Astra chooses from validated operations; ordinary successful model calls are free in the fictional ledger.
3. After calibration and the asteroid survey, interrupt the ten-second launch preview with **Use less fuel**. The conversation records a numerical before/after speed, fuel and ETA comparison, and the trajectory preview changes. The normal 0.04 ly/year speed becomes 0.025. Prefer making this correction before a launch; during an existing coast the preference applies to the next launch, which the interface states explicitly.
4. Let Astra execute the finite stop and the home leg. **Interrupt** invalidates pending actions and responses; **Continue within remaining budget** preserves original permission and spending. **Advance now** skips presentation waiting, never simulated accounting. Coasting advances at most 50 simulated years per checkpoint.
5. Braking is a separate charged action. The arrival receipt checks distance and speed, and the ledger exports as JSON. **Reset same sky** replays the current seed; **New sky** chooses a new random seed. The initial presenter seed is 93741. State is in memory and reload starts over.

## Causal implementation

**Evidence → location.** All 5,044 existing catalogue entries are eligible spawn anchors. The original data supplies angular directions, magnitude and color only. `catalogueWorld` deterministically assigns synthetic 6–18 ly depths by catalogue ID. The engine holds the seeded position and attitude privately; `view()` before calibration exposes only anonymous measured bearings, resources and delegation. Neither the bridge request nor the player UI receives the seed, source identity, position, range or home direction before the fix.

An explicitly synthetic ideal scan obtains eight tags/correspondences, ranges and ship-frame bearings. The solver receives these records and the public synthetic catalogue, never hidden pose. Four sphere equations recover position by pivoted linear elimination; corresponding bearings recover a proper rotation via orthonormal bases. Four additional landmarks check the recovered transform. Fewer than five observations, duplicate IDs, degenerate geometry or inconsistent held-out measurements remain unresolved. The resulting position is used by navigation. Residuals are numerical agreement in a noiseless model, not real-world accuracy estimates. Ordinary game openings are deliberately solvable; ambiguous cases are covered at the solver boundary, not presented as a noisy sensor campaign.

**Human correction → changed controls and cost.** `/api/journey` invokes actual local `gpt-6-astra` with continuing bounded history and a strict allowlisted public-observation envelope. After calibration it receives the asteroid geometry, deposit and operation costs, candidate impulses, gravity changes, reserve, speed, ETA and computed endpoint difference. The model may choose only a current quote ID, change a supported preference, or ask a question. Before the player grants the helm, conversation is read-only and the bridge rejects any proposed execution. Engine-generated quotes, effects and rewards remain private and immutable. Request ID, epoch and revision checks reject interrupted, duplicated and stale replies. No deterministic response is presented as Live Astra. An unavailable bridge pauses without a fictional debit; a busy bridge waits for the earlier request to finish.

**Plan → outcome.** The engine integrates actual current position and velocity with a softened local attraction, not the original binary experiment initial state. Before/after previews share the same snapshot and show original gravity, suppression only, and suppression plus impulse. Suppression costs 6 fuel and holds the source-force multiplier at zero for the remaining lifetime, bounded by the initial 1,000-year mission. An impulse changes velocity immediately and costs 250 fuel per ly/year of velocity change. Restoring gravity without an impulse preserves instantaneous velocity. This is a declared game power, not ordinary propulsion or a physically realistic interstellar gravitational model.

The single stationary asteroid has a 100 km radius, an eight-hour spin, and a declared game operation region of 0.003 ly. Its marker is schematic. The report identifies a polar extraction patch and approach corridor from fixed scene geometry. Reach the asteroid, brake, then pay 3 fuel / 2 credits / 2 years before receiving the finite 32 fuel / 8 credit deposit. The three-credit report remains spent if declined. Route comparison reports gross operation costs, yield, total net fuel including the onward leg at the selected speed, and the stop’s net credit change. Calibration is a separate already-paid six credits.

After suppression, inertial motion is integrated without a hidden snap or teleport. Coast advances actual state and lifetime. Passing into the home region at nonzero speed is not arrival: the final burn must reduce relative speed below 0.00001 ly/year while within 0.002 ly of home. Mining and arrival consume only supported quoted resources. All operations validate affordability before any debit; rewards cannot pay upfront costs. Gross delegated spending is independent of remaining inventory, so mining cannot renew permission. Arrival fuel is reserved before departure, including a minimum onward launch/brake allowance for the stop.

## Verification

- `npm test`: 25 passing tests (11 new journey tests plus 14 preserved astronomy/physics tests).
- `python3 -m unittest discover -s tests -p 'test_*.py'`: 15 passing tests (six new journey-boundary tests plus nine preserved bridge tests).
- Journey tests cover unknown-state privacy, seed replay and first/middle/last anchors, independent calibration, ambiguity/corruption, same-state force previews, pre-calibration raw experiments, pause/resume, revised fuel/ETA, forged/replayed/stale quotes, insufficient resources/reserves, finite depletion, report decline, exact ledger reconciliation, and position-plus-speed arrival.
- Independent read-only review calibrated all 5,044 anchors with varied seeds/attitudes. Maximum held-out residual was 1.064e-9 ly. 163 evenly spread anchors completed a balanced stop-to-home run; all arrived. These are engine checks, not real-world validation.
- Independent gravity-preview convergence check sampled every 101st anchor, comparing 400 and 3,200 integration steps over eight years. Maximum endpoint discrepancy was 9.58e-9 ly.
- Actual desktop browser run used live Astra for calibration, survey and route selection, then an actual human-style fuel correction before commitment. Displayed direct-home comparison: speed 0.04→0.025 ly/year; launch+braking 26.7→19.2 fuel; ETA 294.3→470.9 years. Astra selected the cheaper finite detour and the engine finished after about 474 years, spending 34.3 fuel and 11 credits gross and recovering 32 fuel / 8 credits. Remaining balances: 97.7 fuel, 27 credits, 526 years. Final distance 1.25e-13 ly, speed zero. No fallback response was used. The initial run preceded the cosmetic asteroid-unit and full-net-copy corrections; those preserve accounting and motion.

## Scope and limits

This is a bounded demonstrator with explicit synthetic astronomy, one stationary resource stop and instant velocity changes. No real interstellar distances, noisy astronomical inference, relativity, collisions, radiation, campaign, arbitrary tool generation, durable save system or remote backend were added. The source is client-side and is not an anti-cheat boundary against developer-tool inspection. Public model context is a separate strict schema. Live model latency is variable and is separate from compressed fictional travel time.

Files: `dist/journey.js` (engine), `dist/journey-ui.js` (UI/controller), `dist/journey.css`, `dist/index.html`; `server.py` and `scripts/journey-public.mjs` (local model boundary). Existing authored assets remain in `dist/` per the registered static Site configuration.

Final build check: a second actual live desktop run used the corrected 100 km report and strict delegation field. After explicit delegation, the balanced mining-to-home run completed at about 297 years with 49.2 fuel and 11 credits gross spent, 32 fuel / 8 credits recovered, final balances 82.8 / 27 / 703, final distance 1.85e-14 ly and speed zero. Desktop 1440×900 and mobile 390×844 layouts were inspected; no browser console errors were reported. The preserved observatory loaded and its stellar-studio controls opened successfully.
