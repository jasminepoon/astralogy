## The story in one sentence

Astra helps you understand an unfamiliar sky, reshape a fictional gravity field, and choose a route home whose fuel and time tradeoff you can inspect and change.

## Recovery cues

| Situation | Action and concise presenter language |
| --- | --- |
| Model still working | Keep the real working state visible: “Astra is evaluating the route.” Do not repeatedly submit. If the slot runs out, use a clearly labelled prior recording if one exists. |
| Bridge unavailable | Pause: “The live connection is unavailable.” Show a labelled recorded run only if available; otherwise end at the demonstrated state. |
| Revision rejected or unaffordable | Show the actual explanation: “That alternative doesn't fit this budget.” Do not claim savings. |
| Wrong move or interrupted execution | Use Interrupt. If demonstrating Undo, explain that it rewinds the whole field edit and subsequent flight, time and resources. Mark the rehearsal as recovered rather than uninterrupted. |
| Arrival not verified | Keep the actual state visible. Do not substitute the Earth image or call the run successful. Save the failure for diagnosis. |
